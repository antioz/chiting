## Замечания

1. **ЛЛМ-нестабильность критерия «Свои слова»** (см. сценарий 2): цитата-витрина в 4 прогонах: 0/0, 1/5, 2/9, 0/0. Для боевого античита это значит, что часть копипаст проскакивает с отметкой 1. Кандидат на доработку промпта (усилить критерий 4) — вне рамок task-13.
2. Лестница next на UI доступна только на экране результата (socratic); в сценарии ферсмана next×4 вызваны через api() приложения — поведение бэка идентично, кнопка «Или: ещё один шаг подсказки (лестница)» на result-screen штатно работает (код-ревью app.js), отдельным UI-кликом не гонял.
3. Split-режим подтверждён полностью: разбивка на next#4 (SPLIT_THRESHOLD=4), мини-текст фрагмента f5, review только по in_scope (q1,q2,q5), купон по ставке родителя.
4. read_start/read_end события летят штатно (в логе HTTP 200 a=attempt-event).
5. Puppeteer-специфика для будущих прогонов: кириллица через page.type не даёт keydown (античит 422 suspicious) — печатать посимвольно с диспатчем keydown; top-level `const S` в app.js не виден как window.S — обращаться к S напрямую.
